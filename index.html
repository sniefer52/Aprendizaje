0.3 ¿Qué es Claude Code?

Claude Code es un CLI (programa de línea de comandos) que instalas en tu ordenador. Cuando lo abres, puedes:

  • Hablar con Claude en lenguaje natural
  • Claude lee tu código automáticamente cuando se lo pides
  • Claude edita archivos directamente en tu proyecto
  • Claude ejecuta comandos en tu terminal
  • Claude busca en internet cuando lo necesita

0.4 ¿Qué es COWORK?

COWORK es la capacidad de Claude de crear equipos de agentes que trabajan juntos — como tener un equipo de programadores IA, cada uno especializado.

TÚ │ ▼ ┌─────────────────────────┐ │ AGENTE PRINCIPAL │ │ (Orquestador) │ └───────────┬─────────────┘ │ ┌────────────┼────────────┐ │ │ │ ▼ ▼ ▼ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ Sub-Agente│ │Sub-Agente│ │Sub-Agente│ │ Explorar │ │Planificar│ │ Ejecutar │ └──────────┘ └──────────┘ └──────────┘ │ │ │ └────────────┼────────────┘ ▼ Resultado final

Analizar 100 archivosClaude lee uno a unoMúltiples agentes en paralelo
Tarea muy largaUn agente puede "olvidar" el inicioOrquestador mantiene el hilo
Revisión de códigoUna perspectivaPerspectivas especializadas

Tú: "Crea un archivo calculadora.py con funciones para sumar, restar, multiplicar y dividir" Claude: [Crea calculadora.py] def sumar(a, b): return a + b def restar(a, b): return a - b def multiplicar(a, b): return a * b def dividir(a, b): if b == 0: raise ValueError("No se puede dividir por cero") return a / b

Módulo 3 — Características Avanzadas

⏱ 50 min🔧 Avanzado🎯 Hooks, MCP, Settings, IDE

3.1 Hooks — Automatizaciones

Los hooks son scripts que se ejecutan automáticamente cuando Claude hace algo — como "disparadores" o "gatillos".

EVENTO HOOK │ │ Claude va a usar Bash ──[PreToolUse]──→ echo "Ejecutando..." Claude termina Bash ──[PostToolUse]──→ ejecuta_linter.sh Claude termina mensaje ──[Stop]─────────→ notifica_slack.sh

Ciclo de Vida

Usuario escribe mensaje
↓
PreToolUse → Hook ANTES de usar herramienta
↓
Claude usa herramienta (Read, Bash, Edit...)
↓
PostToolUse → Hook DESPUÉS de usar herramienta
↓
Stop → Hook cuando Claude TERMINA

Configurar Hooks en settings.json

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit",
        "hooks": [{
          "type": "command",
          "command": "npm run lint"
        }]
      }
    ],
    "Stop": [
      {
        "hooks": [{
          "type": "command",
          "command": "echo '✅ Claude terminó'"
        }]
      }
    ]
  }
}

3.4 Settings — Configuración Completa

Jerarquía de Configuración

~/.claude/settings.json ← GLOBAL (todos tus proyectos) tu-proyecto/.claude/settings.json ← LOCAL (solo este proyecto) El archivo LOCAL tiene prioridad sobre el GLOBAL.

Sistema de Permisos

{
  "permissions": {
    "allow": [
      "Bash(npm run *)",    // solo comandos npm run
      "Bash(git *)",        // todos los comandos git
      "Read(**)",           // leer cualquier archivo
      "Write(src/**)"       // escribir solo en src/
    ],
    "deny": [
      "Bash(rm -rf *)",     // NUNCA borrar recursivo
      "Bash(sudo *)"        // NUNCA sudo
    ]
  }
}

Módulo 4 — COWORK Multi-Agente

⏱ 60 min🤖 Avanzado🎯 Orquestación de agentes

4.1 ¿Qué es un Agente?

Un agente es una instancia de Claude que puede recibir una tarea, planificar los pasos, usar herramientas y devolver un resultado.

┌────────────────────────────────────────┐ │ AGENTE │ │ │ │ Entrada: "Encuentra bugs de seguridad │ │ en src/" │ │ │ │ │ ▼ │ │ Planifica: │ │ 1. Listar archivos en src/ │ │ 2. Leer cada archivo │ │ 3. Buscar patrones inseguros │ │ 4. Reportar hallazgos │ │ │ │ │ ▼ │ │ Ejecuta: Read, Bash, WebSearch │ │ │ │ │ ▼ │ │ Salida: "Encontré 3 vulnerabilidades" │ └────────────────────────────────────────┘

4.2 Tipos de Agentes

TipoEspecialidadCuándo usarlo
ExploreBúsqueda en el codebaseEncontrar archivos, funciones, patrones
PlanDiseño de arquitecturaPlanificar soluciones complejas
general-purposeTareas multi-pasoInvestigación y ejecución compleja
claude-code-guidePreguntas sobre Claude CodeDudas sobre la herramienta misma

4.3 Patrón Secuencial vs. Paralelo

Secuencial

Cuándo: B necesita el resultado de A [Agente A: Explorar código] │ │ resultado ▼ [Agente B: Planificar migración] (necesita saber la estructura) │ │ plan ▼ [Agente C: Implementar] Tiempo = A + B + C

Paralelo

Cuándo: A, B y C son independientes [Orquestador] │ ┌──────────┼──────────┐ ▼ ▼ ▼ [Ag. A] [Ag. B] [Ag. C] auth/ api/ db/ Todos corren simultáneamente Tiempo = max(A, B, C)

4.4 ¿Cuándo Usar COWORK?

Un Solo Agente cuando: • Tarea puntual y acotada
• El contexto cabe en una conversación
• No hay tareas independientes
• Es más rápido explicarlo directamente
COWORK cuando: • Analizar 200+ archivos
• Sub-tareas independientes → paralelizar
• Necesitas perspectivas especializadas
• Tarea con muchos pasos complejos
⚠️ CuidadoNo uses COWORK para todo. Añadir sub-agentes tiene coste: más tiempo de coordinación y más tokens. Para tareas simples, un solo agente es más eficiente.

4.5 Cómo Crear Sub-Agentes

// SECUENCIAL — esperar resultado antes de continuar
const resultado = Agent({
  description: "Explorar estructura del proyecto",
  subagent_type: "Explore",
  prompt: "Mapea la estructura completa de src/",
  run_in_background: false  // esperar a que termine
})

// PARALELO — todos al mismo tiempo
Agent({
  description: "Analizar módulo auth",
  subagent_type: "Explore",
  prompt: "Analiza src/auth/ y reporta issues de seguridad",
  run_in_background: true   // no esperar, ejecutar en paralelo
})

Agent({
  description: "Analizar módulo api",
  subagent_type: "Explore",
  prompt: "Analiza src/api/ y reporta issues de seguridad",
  run_in_background: true
})
// Los dos corren simultáneamente

4.6 Comunicación entre Agentes

✅ CorrectoSub-agentes se comunican A TRAVÉS del orquestador. Cada uno reporta sus resultados al orquestador que los integra.
❌ IncorrectoSub-agentes NO se hablan directamente. No hay canal entre ellos. El orquestador es siempre el intermediario.

{

📖 Glosario

Todos los términos técnicos del curso, explicados en lenguaje sencillo.

A

Agent (Agente)

Instancia de Claude que puede recibir una tarea, planificar pasos, usar herramientas y devolver resultados. Base de COWORK.

Agent SDK

Kit de desarrollo para construir y orquestar agentes de IA. Claude Code lo usa para COWORK.

API (Application Programming Interface)

Interfaz que permite que dos programas se comuniquen. La API de Anthropic es la "puerta" para hablar con Claude.

API Key

Contraseña secreta que identifica tu cuenta al usar la API. Empieza con sk-ant-. Nunca la compartas.

C

CLI (Command Line Interface)

Interfaz de línea de comandos — se usa escribiendo texto en la terminal. Claude Code es un CLI.

Claude Code

CLI oficial de Anthropic para interactuar con Claude desde la terminal para tareas de desarrollo de software.

COWORK

Modelo de trabajo donde múltiples agentes Claude trabajan juntos. Un orquestador delega sub-tareas a agentes especializados.

Contexto

Información que Claude tiene disponible: mensajes anteriores, archivos leídos, historial de herramientas usadas.

D

Diff

Diferencia entre dos versiones de un archivo. Claude muestra diffs al editar código para que veas exactamente qué cambia.

H

Hook

Script que se ejecuta automáticamente cuando ocurre un evento en Claude Code (PreToolUse, PostToolUse, Stop, Notification).

M

MCP (Model Context Protocol)

Protocolo estándar que permite a Claude conectarse con servicios externos (GitHub, Slack, bases de datos, etc.).

MCP Server

Programa que implementa MCP y expone herramientas de un servicio externo a Claude.

O

Orquestador

Agente principal en COWORK que divide tareas y coordina a los sub-agentes.

S

Settings (settings.json)

Archivo de configuración de Claude Code: permisos, hooks, MCP servers, variables de entorno.

Slash Command

Comando especial dentro de Claude Code que empieza con /. Ejemplo: /help, /compact.

Sub-Agente

Agente secundario creado por el orquestador para realizar una tarea específica e independiente.

T

Tool (Herramienta)

Capacidad específica de Claude: Read, Write, Edit, Bash, WebSearch, Agent, etc.

Token

Unidad básica de texto que procesa el LLM. ~1 token = 0.75 palabras. Los modelos tienen límites de tokens.

W

Worktree

Copia aislada de un repositorio Git donde un sub-agente puede trabajar sin interferir con el orquestador.

⚡ Cheatsheet

Referencia rápida de todo lo aprendido en el curso.

Instalación

npm install -g @anthropic-ai/claude-code
export ANTHROPIC_API_KEY="sk-ant-..."
claude --version
claude

Slash Commands

/help      → ayuda
/clear     → limpiar pantalla
/compact   → comprimir contexto
/status    → estado del modelo
/init      → crear CLAUDE.md
/review    → revisión COWORK
/fast      → modo rápido

Herramientas

Read       → leer archivo
Write      → crear/sobreescribir
Edit       → editar partes
Bash       → ejecutar comando
WebSearch  → buscar en internet
Agent      → sub-agente COWORK

Hooks — Eventos

PreToolUse   → antes herramienta
PostToolUse  → después herramienta
Stop         → Claude terminó
Notification → Claude notifica

Permisos

"allow": [
  "Bash(npm run *)",
  "Bash(git *)",
  "Read(**)",
  "Write(src/**)"
],
"deny": ["Bash(rm -rf *)"]

Agentes COWORK

Explore      → buscar código
Plan         → diseñar solución
general-purpose → tareas complejas
claude-code-guide → preguntas SDK

Patrones COWORK

Secuencial:
[A]→[B]→[C]  Tiempo = A+B+C

Paralelo (run_in_background: true):
[A][B][C] simultáneo
Tiempo = max(A, B, C)

Modelos Claude

claude-opus-4-7   → máxima capacidad
claude-sonnet-4-6 → uso general
claude-haiku-4-5  → rapidez

Archivos de Configuración

Tu proyecto/ ├── CLAUDE.md ← contexto permanente del proyecto └── .claude/ ├── settings.json ← configuración local (prioridad) └── commands/ ← slash commands personalizados └── mi-comando.md → /mi-comando ~/.claude/ └── settings.json ← configuración global
💡 Tips de Oro ✅ Sé específico en tus instrucciones → mejores resultados
✅ Usa CLAUDE.md para dar contexto permanente del proyecto
✅ /compact cuando la sesión se vuelve lenta
✅ Usa sub-agentes para tareas grandes e independientes
⚠️ Nunca pongas tu API key en archivos que irán a git
⚠️ Revisa siempre los diffs antes de aprobar cambios
