Instalación

npm install -g @anthropic-ai/claude-code
export ANTHROPIC_API_KEY="sk-ant-..."
claude --version && claude

Slash Commands

/help      → ayuda completa
/clear     → limpiar pantalla
/compact   → comprimir contexto
/status    → estado del modelo
/init      → crear CLAUDE.md
/review    → revisión con COWORK
/fast      → modo rápido (Opus)

Herramientas (Tools)

Read       → leer archivo
Write      → crear/sobreescribir
Edit       → editar partes
Bash       → ejecutar comando
WebSearch  → buscar en internet
Agent      → lanzar sub-agente

Hooks — Eventos

PreToolUse   → antes de herramienta
PostToolUse  → después herramienta
Stop         → Claude terminó
Notification → Claude notifica

Permisos en settings.json

"permissions": {
  "allow": [
    "Bash(npm run *)",
    "Bash(git *)",
    "Read(**)",
    "Write(src/**)"
  ],
  "deny": ["Bash(rm -rf *)"]
}

Tipos de Agentes COWORK

Explore      → buscar código
Plan         → diseñar solución
general-purpose → tareas largas
claude-code-guide → dudas SDK

Patrones de Colaboración

Secuencial:
[A] → [B] → [C]
Tiempo = A + B + C

Paralelo (run_in_background:true):
[A] [B] [C] simultáneo
Tiempo = max(A, B, C)

Modelos Claude (2026)

claude-opus-4-7    → máxima capacidad
claude-sonnet-4-6  → uso general
claude-haiku-4-5   → velocidad

Archivos Clave

CLAUDE.md             ← contexto proyecto
.claude/settings.json ← config local
~/.claude/settings.json ← config global
.claude/commands/*.md ← slash commands
