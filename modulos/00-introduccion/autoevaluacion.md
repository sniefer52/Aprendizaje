## Preguntas

### Pregunta 1
¿Qué es Claude Code?

- A) Una página web para chatear con Claude
- B) Un programa de línea de comandos para programar con IA asistida
- C) Un modelo de IA creado por Anthropic

### Pregunta 2
¿Cuál es la diferencia principal entre Claude.ai y Claude Code?

- A) Claude.ai es más inteligente que Claude Code
- B) Claude.ai es solo para web y Claude Code es un CLI para desarrolladores
- C) Claude Code no necesita conexión a internet
- D) Son exactamente lo mismo, solo cambia el nombre

### Pregunta 3
¿Qué significa COWORK en el contexto de Claude?

- A) Una aplicación de videollamadas para equipos
- B) El proceso de escribir código en colaboración con humanos
- C) Un sistema donde múltiples agentes de IA trabajan juntos para completar tareas complejas
- D) Una empresa filial de Anthropic

---

### Pregunta 4
En un sistema COWORK, ¿qué papel juega el "orquestador"?

- A) Es el agente más rápido del equipo
- B) Es el agente principal que divide tareas y coordina a los sub-agentes
- C) Es el agente que habla directamente con el usuario
- D) Es el servidor donde se ejecutan los otros agentes

---

### Pregunta 5
¿Cuándo es más apropiado usar COWORK en lugar de un solo agente?

- A) Siempre, porque es siempre más eficiente
- B) Nunca, porque es demasiado complejo de configurar
- C) Para tareas cotidianas simples como refactorizar una función
- D) Para tareas grandes y complejas que requieren paralelismo o especialización

## Respuestas y Explicaciones

<details>
<summary>👉 Haz clic aquí para ver las respuestas</summary>

### Respuesta 1: ✅ B
**Claude Code es un programa de línea de comandos (CLI) para programar con IA asistida.**

Claude Code se instala en tu ordenador y se usa desde la terminal. No es una web, no es el modelo en sí, y aunque tiene funciones similares a un editor de código, es una herramienta de IA que *interactúa* con tu editor.

---

### Respuesta 2: ✅ B
**Claude.ai es la interfaz web para uso general. Claude Code es el CLI especializado para desarrolladores.**

Claude.ai sirve para chatear con Claude desde el navegador, para cualquier uso. Claude Code está diseñado específicamente para el desarrollo de software: puede leer archivos de tu proyecto, editar código, ejecutar comandos en la terminal, etc.

---

### Respuesta 3: ✅ C
**COWORK es el sistema multi-agente donde varios agentes de Claude trabajan juntos.**

El término COWORK describe la capacidad de orquestar múltiples agentes especializados que trabajan en paralelo o en secuencia para completar tareas que serían demasiado grandes o complejas para un solo agente.

---

### Respuesta 4: ✅ B
**El orquestador es el agente principal que coordina el trabajo del equipo.**

El orquestador recibe la tarea del usuario, la divide en sub-tareas, las asigna a los sub-agentes apropiados, recoge sus resultados y produce la respuesta final. Es como el "director de proyecto" del equipo de IA.

---

### Respuesta 5: ✅ D
**COWORK es más apropiado para tareas grandes que requieren paralelismo o especialización.**

Para tareas simples (refactorizar una función, corregir un bug simple), un solo agente es más eficiente. COWORK brilla cuando hay que: analizar muchos archivos en paralelo, combinar perspectivas especializadas, o gestionar tareas muy largas con muchos pasos.
