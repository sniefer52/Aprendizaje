## ✅ Cómo Usar Esta Guía

```
1. Lee la lección del módulo completa, de arriba a abajo
        │
        ▼
2. Practica los ejemplos en tu terminal
        │
        ▼
3. Completa la autoevaluación al final
        │
        ▼
4. Revisa tus respuestas y entiende los errores
        │
        ▼
5. Pasa al siguiente módulo
```

> 💡 **Tip:** No saltes módulos. Cada uno construye sobre el anterior.
>
> ⚠️ **Importante:** Claude Code es interactivo. Tendrás que probarlo en tu propia terminal para aprender de verdad.

## 📋 Requisitos Previos

| Requisito | ¿Necesario? | Notas |
|-----------|-------------|-------|
| Conocimientos de programación | ❌ No | Ideal pero no obligatorio |
| Saber usar la terminal | ✅ Básico | Solo comandos simples: `cd`, `ls` |
| Node.js instalado | ✅ Sí | v18 o superior |
| Cuenta de Anthropic | ✅ Sí | Para obtener API key |
| Git instalado | 💡 Recomendado | Para el proyecto final |

## 🏆 Sistema de Progreso

Al final de cada módulo encontrarás una autoevaluación. Usa esta escala:

```
  0-3 correctas  →  Repasa la lección antes de continuar
  4   correctas  →  Bien, puedes continuar
  5   correctas  →  Excelente, dominas el módulo!
```
