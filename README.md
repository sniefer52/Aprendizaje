# Aprendizaje

Entorno de aprendizaje autoguiado con Claude Code basado en los **L-99: 99 Problemas de Programación**.

## Empezar

Lee el tutorial completo antes de comenzar:

**[L99_Tutorial.md](./L99_Tutorial.md)**

## Estructura

```
Aprendizaje/
├── L99_Tutorial.md   ← Guía completa del espacio y los 99 problemas
├── soluciones/       ← Tus soluciones (una por archivo: p01.py, p02.py, ...)
└── notas/            ← Apuntes personales opcionales
```

## Flujo rápido

1. Lee `L99_Tutorial.md` de principio a fin (una vez)
2. Crea `soluciones/p01.py` e intenta el primer problema
3. Usa `claude` en la terminal para pedir pistas o revisión de código
4. Haz commit al terminar cada problema
5. Repite hasta el P99
